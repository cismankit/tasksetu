# India State Expansion Plan

## Phase 1 — MP (current)
Deep pack: 5 templates + national overlays.

## Phase 2 — Rajasthan (Q3 2026)
- Similar e-District model (`emitra.rajasthan.gov.in`)
- Shared desert/rural persona overlap with MP
- Hindi UI reuse

## Phase 3 — Uttar Pradesh (Q4 2026)
- Largest student volume
- CSC/e-District complexity — higher research cost

## Phase 4 — Maharashtra (2027)
- Marathi language requirement
- Urban professional persona weight

## Phase 5 — Bihar, Karnataka, Tamil Nadu
- Language investments: Bhojpuri optional, Kannada, Tamil

## Expansion criteria per state
1. ≥3 validated user interviews
2. Official portal links verified
3. Minimum 5 task templates
4. Hindi + state language roadmap
5. No legal blocker on assistance wording

## Resource model
- Start with research issues in GitHub Projects
- Community contributors for district notes (governed review)
