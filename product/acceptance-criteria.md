# Acceptance Criteria

## Onboarding
- [ ] User can complete flow in < 2 minutes
- [ ] Language persists across sessions
- [ ] Region drives template availability

## Dashboard
- [ ] Shows ≥1 recommendation for student with marksheet only
- [ ] Pending task count accurate
- [ ] Quick action opens task search

## Document vault
- [ ] Upload image/PDF to private storage
- [ ] Filter by type and family member
- [ ] Expiry warning 30 days before

## Task checklist
- [ ] Create from MP income certificate template
- [ ] Step completion persists
- [ ] Progress percentage correct
- [ ] WhatsApp message generates with doc list

## Recommendations
- [ ] Student + marksheet → income cert or scholarship suggestion
- [ ] Shopkeeper → shopkeeper pack
- [ ] Expiry within 30 days → reminder suggestion

## Reminders
- [ ] Schedule local notification
- [ ] Snooze + dismiss

## Status tracker
- [ ] CRUD status cards
- [ ] Follow-up date triggers reminder suggestion

## Receipts
- [ ] Add with amount, category, date
- [ ] Optional image attach

## Non-functional
- [ ] Typecheck passes in CI
- [ ] No secrets in repo
- [ ] RLS enabled on Supabase tables
