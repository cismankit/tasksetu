# App Flow

## First launch
```
Welcome → Language → Region → User Type → Categories → Family mode → Dashboard
```

## Core loops

### Start a task
```
Dashboard → Search/Template → Task Detail (checklist) → Complete steps
         → Add missing docs → Set reminders → Share WhatsApp
```

### Document vault
```
Dashboard → Vault → Add Document → Type/Expiry/Family assign
         → Document Detail → Set reminder
```

### Track application
```
Dashboard → Status Tracker → Add → Update status → Set follow-up reminder
```

### Receipt
```
Dashboard → Receipts → Add → Photo/Amount/Category → Link task (optional)
```

## Navigation (MVP)
Bottom tabs: Home | Tasks | Docs | More (Receipts, Status, Settings)

## Error states
- Offline: show cached templates, queue uploads
- Missing Supabase: local-only mode banner
