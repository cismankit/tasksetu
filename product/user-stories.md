# User Stories

## Onboarding
- As a **student**, I want to select MP and Hindi so that checklists match my region.
- As a **parent**, I want family mode so that I manage kids' documents separately.

## Dashboard
- As a **busy user**, I want to see pending tasks and recommendations so that I know what to do next.

## Documents
- As a **user**, I want to upload Aadhaar with expiry reminder so that I renew on time.
- As a **parent**, I want to assign documents to children so that admission packs are organized.

## Tasks
- As a **student**, I want income certificate checklist so that I don't visit Tehsil twice.
- As a **user**, I want WhatsApp share so that I can request docs from family.

## Reminders
- As a **user**, I want local notifications for follow-ups so that I don't forget portal checks.

## Receipts
- As a **shopkeeper**, I want monthly UPI summary so that accounting is easier.

## Status
- As a **user**, I want to log application number and status so that I track progress manually.

## Settings
- As a **user**, I want to change language and region so that content stays relevant.
