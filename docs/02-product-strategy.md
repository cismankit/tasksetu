# Product Strategy

## Strategic bet
India's next wave of useful consumer software is not broad AI chat — it is **structured workflow software** that respects local context (state, language, document culture).

## Wedge market
**Madhya Pradesh** as the first deep regional pack, layered on **India-national** templates. MP offers representative mix of urban/rural users, strong e-District adoption, and high student/government-form volume.

## Positioning
| Alternative | TaskSetu difference |
|-------------|---------------------|
| ChatGPT | Guided checklists, not open-ended chat |
| DigiLocker | User-owned vault + task workflows, not issuer integration |
| Notion/Todoist | Life-admin templates with regional intelligence |
| WhatsApp | Structured sharing + reminders, not message chaos |

## Go-to-market phases
1. **Private beta** — MP students, parents, shopkeepers (50–100 users)
2. **Public beta** — GitHub Pages waitlist, Play Store TestFlight
3. **Regional expansion** — Rajasthan, UP, Maharashtra template packs
4. **Monetization** — freemium family tier, business receipt packs

## Build principles
1. Mobile-first (Android priority)
2. Offline-tolerant local reminders
3. Privacy-first (RLS, private storage)
4. Docs before code for new regions
5. Rule-based intelligence before LLM costs

## Competitive moat
- Curated regional task templates with maintenance discipline
- Family + document + reminder graph
- Trust positioning (no fake gov integration)
- Community-driven regional pack contributions (future)
