# Task Opportunity Map

## Scoring dimensions
- **Frequency** — how often users face this task
- **Pain** — confusion, time, anxiety
- **MVP fit** — achievable without integrations
- **Regional depth** — benefits from state pack

## Tier 1 — MVP priority (MP + national)
| Task | Users | Pain | Template ID |
|------|-------|------|-------------|
| Income certificate prep | Student, farmer, parent | High confusion on docs | `mp-income-certificate` |
| Scholarship document pack | Student | Deadline anxiety | `mp-scholarship-pack` |
| Caste certificate prep | Student | Field verification surprises | `mp-caste-certificate` |
| Domicile certificate | Student, job seeker | Residence proof confusion | `mp-domicile-certificate` |
| Exam/admission pack | Student | Scattered marksheets | `mp-student-exam-pack` |
| Essential ID pack | All | Lost docs | `in-national-document-pack` |
| Monthly UPI receipt summary | Shopkeeper | Manual screenshots | `in-shopkeeper-pack` |
