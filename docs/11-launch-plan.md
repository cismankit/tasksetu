# Launch Plan

## Pre-launch checklist
- [ ] 20 beta testers recruited (MP-focused)
- [ ] Privacy policy draft published
- [ ] Landing page live on GitHub Pages
- [ ] Play Store internal testing build
- [ ] TestFlight iOS build (optional for MVP)
- [ ] Support email / GitHub Discussions enabled
- [ ] Crash reporting (Sentry optional)

## Beta cohort (target: 50 users)
| Segment | Count | Recruitment |
|---------|-------|-------------|
| Students | 20 | College WhatsApp groups, Bhopal/Indore |
| Parents | 15 | Family networks |
| Shopkeepers | 10 | Local market associations |
| Others | 5 | Farmers, gig workers |

## Launch sequence
1. **Soft launch** — private link, feedback form
2. **Iterate 2 weeks** — fix top 5 friction points
3. **Public beta waitlist** — landing page CTA
4. **Regional PR** — local tech communities, not national yet

## Messaging
- Primary: "Forms, documents, reminders — sorted."
- Hindi: "Kaam ho simple. Life ho sorted."
- Avoid: "AI assistant", "official government app"

## Success criteria (30-day beta)
- 40% WAU/MAU
- ≥2 tasks started per active user
- ≥1 document uploaded per active user
- NPS ≥ 30 from interviews

## Rollback plan
- Feature flags via env for Supabase sync
- Offline mode if backend unstable
