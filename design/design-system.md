# Design System

## Brand
- **Primary:** `#2563EB` (trust blue)
- **Secondary:** `#059669` (completion green)
- **Background:** `#F8FAFC`
- **Text:** `#0F172A` / muted `#64748B`

## Typography
- System font stack (San Francisco / Roboto)
- Title: 28px bold
- Section: 18px semibold
- Body: 16px regular
- Caption: 14px muted

## Spacing scale
4 / 8 / 16 / 24 / 32 / 48 px — see `packages/ui/src/tokens/`

## Components (packages/ui)
- Button (primary, secondary, ghost)
- Card (mobile: inline styles until NativeWind)
- Input, Select — Phase 4

## Principles
- Calm, not cluttered
- One primary action per screen
- Plain language (Hindi + English)
- Large tap targets (min 44px)

## Accessibility
- WCAG AA contrast on text
- Screen reader labels on icons (Phase 4)
- Respect system font size
